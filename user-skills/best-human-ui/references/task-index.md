# SHIGタスク索引

収録日: 2026-07-16

依頼の対象に近いタグを1〜4個選び、対応する原則番号だけをカテゴリ別資料から読む。似たタグをすべて選ぶ必要はない。

| 公式タグ | 主な対象 |
|---|---|
| `shig-accessibility` | 読み上げ、文字拡大、色以外の手掛かり、時間制限 |
| `shig-animation` | 状態遷移と往復する動き |
| `shig-clarity` | 意味、見分け、ラベル、視覚的な説明 |
| `shig-consistency` | 表現、挙動、配置、慣用表現の統一 |
| `shig-controllability` | 利用者の主導権、可逆性、自由な作業順序 |
| `shig-efficiency` | 操作量、選択時間、自動化、主要タスク |
| `shig-error` | 誤操作の予防、回復、エラー表示 |
| `shig-feedback` | 応答時間と操作箇所に近い反応 |
| `shig-form` | 入力項目、選択肢、初期値、ボタン、入力形式 |
| `shig-guidance` | 制約、候補、説明、次の行動 |
| `shig-guts` | 低確率事象、確認画面、仕様の割り切り |
| `shig-integrity` | データ整合性、上限、不要要素、視覚的な秩序 |
| `shig-internationalization` | 文化差、翻訳後の長さ、記号の意味 |
| `shig-layout` | スクロールの手掛かり、階層方向、画面遷移 |
| `shig-memory` | 記憶負荷、位置の保存、未来の作業用の印 |
| `shig-mobile` | 小さい画面での情報階層 |
| `shig-navigation` | 情報分類、現在地、帰還経路、項目位置 |
| `shig-object-orientation` | オブジェクト、ビュー、直接操作、状態同期 |
| `shig-simplicity` | 要素削減、段階的な開示、単純な操作の維持 |
| `shig-speculative` | 仮想世界の見せ方、新しい意味、社会への影響 |
| `shig-suggestion` | 入力候補とスクロール可能性の示唆 |
| `shig-tidiness` | グリッド、余白、揃え、包含関係 |
| `shig-touch` | タッチ対象、ジェスチャ、当たり判定 |
